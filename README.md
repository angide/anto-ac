# Website Service AC — GitHub Pages

Template static HTML/CSS/JS untuk Anto AC yang siap di-upload ke GitHub Pages.

## File
- `index.html` — halaman utama
- `style.css` — seluruh desain/responsive
- `script.js` — tombol WhatsApp
- `assets/favicon.svg` — favicon

## Sebelum dipublish
1. Buka `script.js`.
2. Ganti `WA_NUMBER` dengan nomor WhatsApp bisnis dalam format internasional tanpa `+`.
3. Di `index.html`, ganti nama Anto AC, nomor telepon, email, area layanan, harga, dan konten lain sesuai bisnis Anda.
4. Upload seluruh isi folder ke repository GitHub.
5. Aktifkan GitHub Pages dari Settings → Pages → Deploy from branch → main → /(root).

Desain dibuat sebagai website static mandiri dengan struktur landing page service AC profesional, terinspirasi dari referensi yang diberikan, bukan menyalin aset/gambar/kode proprietary situs referensi.
